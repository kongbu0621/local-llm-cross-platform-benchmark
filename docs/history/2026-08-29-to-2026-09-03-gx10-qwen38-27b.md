# GX10 / Qwen3.8-27B 实测历史（2026-08-29 ～ 2026-09-03）

本页记录本仓库第一轮 GX10 / Qwen3.8-27B 实测从 benchmark 基础设施准备、BF16/FP8/NVFP4 运行时验证、Formal100 性能测量，到硬件 profiler gate 冻结的过程证据与结论边界。

## 结论边界

- 本页只记录真实完成的 GX10 实测，不用配置上限补空缺。
- `Formal100` 不是仓库定义的 `E2E@32K`：本轮是 **32768 input + 256 output**；`E2E@32K` 必须是 32768 input + 32768 output。
- FP8 / NVFP4 profiler gate 证明的是对应 runtime/kernel 路径被实际触发，不等价于质量结论，也不能把 PM Sampling cycles 当作 FLOPs 或跨精度性能比。
- FP8 模型包含 `modules_to_not_convert`；NVFP4 模型也是 mixed precision/compressed-tensors 路径，均不得描述为“整模型完全采用该精度”。
