# Qwen3.8-27B / GX10 — 结果分表详情（2026-09-03）

本页是 README 首页结果总表的分表详情页。这里只汇总已经完成并有证据链支持的 GX10 / Qwen3.8-27B 实测；配置上限、计划测试和未完成测试不进入结果表。

> **重要语义：** 当前 Formal100 是 `32768 input + 256 output`，不是仓库定义的 `E2E@32K`。`E2E@32K` 固定要求 `32768 input + 32768 output`。
